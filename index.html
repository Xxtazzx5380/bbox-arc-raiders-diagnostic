Diagnostic navigateur
Teste la résolution DNS via DNS-over-HTTPS, puis le temps de réponse de quelques destinations web.
Prêt.

1. Comparateur DNS (DoH)

Le navigateur demande la résolution à Cloudflare et Google via HTTPS. Ce n'est pas exactement le même test que les requêtes DNS UDP utilisées par la PS5.

2. Latence web

Temps aller-retour approximatif d'une requête HTTPS vers des endpoints publics. Ce n'est pas un ping ICMP et ça ne cible pas le serveur ARC Raiders.

3. Contrôle local

GitHub Pages ne peut pas envoyer de ping ICMP, accéder directement au réseau local, ni mesurer les pertes de paquets comme un programme natif.

Pour le diagnostic complet
Lance le moteur Python Windows depuis le ZIP fourni dans la conversation : il mesure le ping ICMP, les pertes et le ping sous charge depuis ton PC.

Comprendre les résultats

  • Le DNS le plus rapide n'est pas forcément celui qui réduit le ping en partie.
  • La mesure navigateur dépend du navigateur, du cache, du HTTPS, du routage et de CORS.
  • Le ping en jeu dépend du trajet réseau vers le serveur de partie et de l'état de ce serveur.
  • Pour comparer correctement, fais plusieurs séries, dans les mêmes conditions, et ferme les téléchargements en cours.
